# Pesquisa-de-Opini-o
📊 Pesquisa de Satisfação - Este é um programa também feito em Python, com o intuito de coletar a opinião de clientes sobre o atendimento de uma empresa.

💻 Funcionamento:
- O programa roda de forma automática usando uma estrutura de repetição (for).
- Ele pede o nome, a idade e a nota do atendimento (1 para Excelente, 2 para Bom, 3 para Ruim) de cada pessoa.
- No final, ele soma tudo e mostra na tela a quantidade total de votos "Excelente" e "Ruim".
